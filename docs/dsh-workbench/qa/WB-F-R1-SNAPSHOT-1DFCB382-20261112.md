# F 独立验收 R1 快照解码

接受 [PR #284](https://github.com/TongAITech/opencode-test-digital-employee/pull/284) 精确源 `1dfcb38297fdac294fbaa8834be588a4c048af1e` 的独立快照解码组件。

- 在精确检出上执行新增套件，4 通过，零跳过。
- 独立探针使用真实 RC72StateMachine 写入批次与十节点，再追加一条内容相同、事件 ID 不同的批次事件。原始账本与 LF、CRLF 内存输入各解码 12 条，与原始迭代器逐字段一致。删除临时账本后禁止两种文件打开入口，已固定的快照仍可完整解码。中文、补充平面字符、不同 Unicode 归一形式与有限小数保持现有 JSON 解码语义。
- 8 个独立拒绝样本包括转义后重名字段、孤立代理字符、指数溢出、非有限常量、坏 UTF-8、非对象及两种未完成尾部。完整快照须消费到迭代结束才可接受。
- 验收覆盖纯字节解码。文件获取及大小上限、账本权威、事件语义和生产准入属于调用层。现有回放入口未改变。
