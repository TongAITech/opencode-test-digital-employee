1. 375×812手机宽度、Kiritimati浏览者时区：日历右边界≤376px且自身scrollWidth≤clientWidth；实际2024年2月29个格、同日两条真实PG资产。英文切换、12月年视图、键盘Enter导航并保留焦点；全局投产日期仍2026-11-12。0001-01-01前导航禁用、9999-12-31后导航禁用。
2. 将每次实际后端读取改为page_size=1，使用PG产生的真实签名游标逐页读取。第2页响应交付暂挂时，没有部分资产或已知数量；末页真实响应的日期被故意破坏为2024-02-30，最终整体ERROR/INVALID_CALENDAR_DATE，零已显示资产，PG原资产仍3。恢复正常HTTP后可重新读取，不将部分成功留下。
3. 从闰日创建资料，真实POST已提交但丢失HTTP响应。切年/翻年、切到外Scope后原未知请求仍保留且不可错误写新范围。切回原Scope并换为同项目有写权Bob，原Alice context重试409且总资产仍4；回到Alice重试取原结果，总outbox仍4，无重复创建。
4. 实际删除Alice的PG ACL：资产刷新403清空旧标题/行并显示未知数量；Scope再验证403后格子与日期上下文清空。重授后恢复读取，再暂挂一个已经完成的真实旧Scope响应，切批次后交付迟到结果，不回填旧事件或格子。全过程无页面异常；原R1仍为空字节。

## 附录A：独立公历oracle

```python
import calendar,datetime,json,pathlib,subprocess
module=pathlib.Path('rc7_admin/static/workbench/calendar-model.mjs').resolve().as_uri()
years=[1,4,99,100,400,1600,1700,1900,1999,2000,2024,2100,2400,9999]
source="import {monthCells,shiftDate} from "+json.dumps(module)+";const years="+json.dumps(years)+";const rows=[];for(const y of years)for(let m=1;m<=12;m++){const s=String(y).padStart(4,'0')+'-'+String(m).padStart(2,'0')+'-01';rows.push([y,m,monthCells(s)]);}const daily=[];for(const [y,m,cells] of rows)for(const d of cells.filter(Boolean))daily.push([d,shiftDate(d,'day',-1),shiftDate(d,'day',1)]);console.log(JSON.stringify({rows,daily}));"
value=json.loads(subprocess.run(['node','--input-type=module','-e',source],capture_output=True,text=True,check=True).stdout)
for year,month,cells in value['rows']:
    assert cells==[None if day==0 else f'{year:04d}-{month:02d}-{day:02d}' for week in calendar.monthcalendar(year,month) for day in week]
for text,previous,following in value['daily']:
    for amount,actual in [(-1,previous),(1,following)]:
        try: expected=(datetime.date.fromisoformat(text)+datetime.timedelta(days=amount)).isoformat()
        except OverflowError: expected=None
        assert expected==actual
print('PASS',len(value['rows']),'months',len(value['daily']),'dates')
```
