# A E02 独立义务批次一致性修复

D263/F264调查发现旧E02只在ETU引用义务时检查该义务的批次。A使用真实PG Scope、真实HTTP和临时R1正式对象写入端，复现同Mission/release但外批次的未引用义务可使graph返回200。可见响应本身未包含义务行，缺口在读取一致性校验。初次测试fixture漏填必要oracle_refs，已补齐后再取得真实200反例，产品红灯1.57秒。

E02现在逐条核验本次读入的全部义务批次，ETU继续核自己的批次和所引用的义务身份。真实同批次的独立义务继续允许。跨批次义务使graph与workitems均返回503 R1_LINEAGE_UNRESOLVED，测试核临时R1字节保持。真实PG相关37项实际通过（17.73秒）。

本修复范围为既有只读E02的一致性检查。正式独立runtime batch mapping、源事件唯一性与历史不漂移依D263/F264增量另行实现。待F独立精确源复验。
