# Concrete Code tools at the model boundary

Production Mission factories and configuration bindings require these exact
registered tools for both Code producer and independent Code reviewer:

* mcp__pfc_aitest_rc7__git_show_revision
* mcp__pfc_aitest_rc7__git_diff
* mcp__pfc_aitest_rc7__codegraph_mcp_tools
* mcp__pfc_aitest_rc7__codegraph_mcp_call

The former `git`/`codegraph` names are evidence capability categories. The
production DSH policy deliberately removes such aliases from model-visible
tools, so granting only aliases made the real model projection empty. The
native factory now refuses that binding. Registered concrete names are passed
through the N3 pipeline into the signed analyzer lease and durable handoff
record; producer and reviewer retain both Git and CodeGraph requirements.

Standalone older component handoff records/defaults remain readable through an
explicit legacy toolset variant. That variant is not admitted by the production
Mission factory or configured binding. Mixed aliases, arbitrary category-like
names, GitNexus in place of Git and wildcard sets cannot substitute for the
registered native toolset. Canonical tool ordering is stable on cold rebuild.

CodeGraph discovery/catalogue/probe calls are not graph-query execution.
Java-changing analysis requires an observed graph execution call; the shared
R1 Code proof reader groups discovery outside actual graph evidence. The
independent reviewer cannot satisfy its graph evidence requirement using only
discovery. Neither a healthy CodeGraph process nor a tool catalogue supplies
professional source-impact proof.

The actual generated production policy is exercised in a separate Node process:
the four registered tools remain visible, ungranted execution is refused and a
missing graph execution tool blocks prompt assembly. N3 scoped protocol-child
regressions exercise named leases/observations and cold continuation. These are
engineering proofs of binding and policy execution, not actual bank model
sessions or complete per-target Git/CodeGraph result provenance. Native
accepted-repository/revision call-time fences and professional model/provider
binding remain C07 work.

The owned controller authority key is also excluded from both generic scoped
source reads and original N1 resources, even when its bytes decode as UTF-8.
Renaming a symlink does not make the authority file readable. This is a tool
boundary; it is not an operating-system filesystem sandbox.
