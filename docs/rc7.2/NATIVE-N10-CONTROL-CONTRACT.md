# Native N10 advancement and product-driver composition

`NativeN10ControlService` composes the concrete original expected-scope provider,
accepted N9 service, actual measurement, canonical intake and independent path
diagnosis services. All must share the same R1, source and owned provider graph;
callbacks and foreign provider instances are refused. ReleaseBatchDriver accepts
it as `n10_pipeline` and checks that it belongs to the same N7/N9/original N1
scope graph. Recorded native measurement history cannot restart with that
provider omitted. Accepted N1..N9 prefix gates remain fully audited.

The service freezes/audits original scope, reaudits accepted N9, collects each
original Application's fixed coverage target, binds actual uncovered units and
advances supported independent diagnosis. Unmapped/ambiguous gaps or unknown
process results return explicit investigation HOLD. Qualified unique observed
paths register original-scope pending N8 investigation work. No business
execution, report read or unknown diagnostic process is automatically repeated.

When intake can proceed, native convergence is computed from its actual proof
providers and current original denominator. The result includes the canonical
snapshot, blockers and pending investigation WorkItem IDs. Missing original
levels remain missing even if the actual coverage report is 100%.

This advancement route does not yet author a terminal N10 Delivery/Gate or
Mission completion. A genuinely converged fact snapshot still requires the
explicit terminal review closure (`N10_TERMINAL_REVIEW_REQUIRED`). Professional
repair/exclusion and full physical layer qualification also remain open. This
is an intentionally visible construction boundary, not a redefinition of the
final complete-runtime/full-portable-package objective.

The full original source fixture runs through actual original N1 MCP input
capture, all N2/N3/N4 parent obligations, N5/N6 readiness, actual native N7 HTTP
processes/cleanup/independent acceptance, N9 and actual N10 report collection.
The original 28 Cases cover 78 canonical obligations (all L3 in this fixture),
with 28 actual business calls and one actual coverage read. Original policy
retains all seven required levels. Full run passed in 687.41s and correctly
remains NOT_CONVERGED. Re-entry launches no additional source worker/business
call/report read; removing the native N10 provider refuses before new writes.
This test has a bounded 900-second file allowance, like the inherited full N7
fixture; other default platform time limits remain unchanged.

The smaller coverage fixture deliberately lacks the complete N4 parent-source
population. Trying to drive its accepted prefix through the product controller
was correctly refused by the existing parent guard. The guard was preserved;
the full test replaced that insufficient controller evidence. Initial domain
and external source/tool approvals remain engineering fixtures, not bank tool
observations, physical L1..L7 qualification or Field/BANK_FINAL.
