## 2. Confirmed blocker A — OpenCode 1.18.3 custom-tool return contract mismatch

Exact upstream OpenCode authority is release target commit:

`anomalyco/opencode@c69abee0c73253aebae65e87e4e1b9bfa8c38021`

Public plugin contract:

`packages/plugin/src/tool.ts`

`ToolResult` is only:

```text
string
OR
{
  title?: string,
  output: string,
  metadata?: object,
  attachments?: ...
}
```

Exact OpenCode v1.18.3 registry behavior:

`packages/opencode/src/tool/registry.ts`

For custom plugin tools, a non-string result is treated as a ToolResult envelope and the host reads `result.output` before truncation.

Current project custom-tool bridges at authorized pre-repair head:

```text
workspace-template/.opencode/tools/aitest.ts
blob = 42994065e8bdb86fdd044cf8cc702ab8bd623624

workspace-template/.opencode/tools/pfc.ts
blob = acad738d1bb6a3fca5fb6c3c9028a0c60f3bdd85

workspace-template/.opencode/tools/aitest_human_gate.ts
blob = 65c5646afa8fd20a455051fad4cf6a826f3ad50a
```

All three may return parsed domain objects directly from their internal bridge functions. That return shape is outside the exact OpenCode 1.18.3 public `ToolResult` contract and can produce a host-side failure when `result.output` is read from a raw domain object.

Formal classification:

```text
ROOT_CAUSE_A = PROJECT_OPENCODE_TOOL_BRIDGE_RETURN_SHAPE_INCOMPATIBLE_WITH_OPENCODE_1_18_3
OPENCODE_CORE_DEFECT = NOT_ESTABLISHED
PROVIDER_MODEL_DEFECT = NO
EXPECTED_OS_DIFFERENCE = NO_EVIDENCE
```

### Required repair boundary A

All exported project custom tools under the three files above must return a valid exact OpenCode 1.18.3 `ToolResult`.

Allowed forms:

```text
1. JSON/text string
OR
2. { output: <string>, optional title/metadata/attachments }
```

The underlying canonical domain object may be serialized for the model/tool host, but its product semantics, durable references, truth source, status, Mission/Plan/Task/Attempt/Session/HumanGate identifiers and error meaning must not be weakened or invented.

The repair must cover the shared root cause across:

- `aitest.ts` Director/G3/G4/G5/custom worker surfaces;
- `pfc.ts` truth/command surfaces;
- `aitest_human_gate.ts` resume surface.

Repairing only the single Director status call is insufficient.
