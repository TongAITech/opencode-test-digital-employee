# Human Loop and Teaching Protocol

HumanTask types include AUTH, MFA, OTP, CAPTCHA, FACE, BUSINESS_CONFIRMATION, REVIEW, DATA_INPUT, SHOWCASE, APPROVAL and DEMONSTRATION.

Controlled Browser uses an isolated profile and an exclusive HUMAN/AI lease. Sensitive field values are recorded only as `<SECRET_INPUT>`. A demonstration creates a Teaching Event, then a Skill Candidate. Promotion requires replay PASS, regression PASS and human review.
