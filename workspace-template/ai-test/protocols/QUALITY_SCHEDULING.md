# L1–L7 Quality Scheduling Protocol

L1–L7 are configurable test layers. The Scheduler reacts to lifecycle events and computes an applicability matrix per Requirement, SST, Layer and Dimension. Requirement Campaigns test changed/directly impacted scope; Release Campaigns add carried/regression/cross-requirement/high-risk scope.

Performance and Security are dimensions/specialized layers applied per SST. Defect retest scope is derived from original observations, fix diff, impact analysis and downstream obligations.
